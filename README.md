# ZoneHunt

ZoneHunt is a real-time GPS-based multiplayer hide-and-seek game for Android and iOS.

Players join a lobby, split into Hunters and Hiders, and compete inside a shrinking play area. The game combines battle royale-style zone mechanics with real-world GPS movement and team-based visibility.

# Core Gameplay

## Teams

### Hiders
Can see:
- Their own location
- Other hiders
- Active zone
- Active red zone
- Remaining hider count

Cannot see:
- Hunters

### Hunters
Can see:
- Their own location
- Other hunters
- Active zone
- Active red zone
- Remaining hider count

Cannot see:
- Hiders

---

# Red Zone

A smaller reveal zone inside the main zone.

Players inside the red zone become visible to everyone.

Visible to:
- Hunters
- Hiders

The red zone changes location periodically throughout the game.

---

# Zone System

## First Zone

The host selects:

- Center location on map
- Starting radius

All players can view:
- First zone location
- First zone boundary
- Game settings

---

## Future Zones

Future zones are generated by the server.

The host DOES NOT know where future zones will be.

This prevents unfair advantages.

---

## PUBG-Style Shrinking

Zones shrink continuously over time.

Example:

```text
1000m
 ↓
850m
 ↓
700m
 ↓
550m
 ↓
400m
 ↓
250m
 ↓
100m
```

Each zone consists of:

### Wait Phase

Zone remains unchanged.

### Shrink Phase

Zone gradually shrinks toward the next zone.

---

# Hide Phase

When the host starts the game:

```text
Hide Phase Begins
```

Hiders receive a configurable amount of time to hide.

Hunters must wait until the hide timer finishes.

Example:

```text
Hide Time: 5 minutes
```

After the timer expires:

```text
Hunt Phase Begins
```

The shrinking zone system then becomes active.
